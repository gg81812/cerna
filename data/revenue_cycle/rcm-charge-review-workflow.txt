# Cerner Charge Review Workflow Guide

## Overview

Charge review is the process of auditing charge lines generated by clinical activity before they are included in a claim submission to a payer. Accurate charge review prevents claim denials, reduces compliance risk, and maximizes appropriate reimbursement. In Cerner Millennium, charge review is performed using the Charge Review module (part of the Revenue Cycle suite).

## Charge Flow from Clinical Event to Claim

1. Clinical service is rendered (order placed, procedure performed, note signed).
2. Charge trigger fires → charge line created in the Charge Review queue.
3. Charge scrubbing rules run → flags potential errors automatically.
4. Charge reviewer audits and approves charge lines.
5. Approved charges are batched into a claim.
6. Claim submitted to payer via clearinghouse.

## Accessing the Charge Review Module

1. Open the Cerner Revenue Cycle applications from the Cerner toolbar.
2. Click "Charge Review" or navigate to Revenue Cycle > Charge Services > Charge Review.
3. The Charge Review queue opens showing encounters with pending charge review.

## Charge Review Queue

### Queue Organization

The charge review queue displays encounters organized by:
- **Status**: Pending Review, Edit Required, Approved, Denied
- **Account type**: Inpatient (IP), Outpatient (OP), Emergency (ED)
- **Department / Cost Center**: ICU, OR, Radiology, Lab, etc.
- **Service Date**: older encounters are typically prioritized

Columns in the queue:
- Patient Name, MRN, FIN
- Account Type and Financial Class (Medicare, Medicaid, Commercial, Self-Pay)
- Service Date and Discharge Date (for IP)
- Total Charges (sum of all charge lines on the account)
- Edit Count (number of automated scrubbing flags)
- Days Since Service (charge lag indicator)
- Reviewer Assignment

### Filters and Worklists

Charge reviewers typically work from personalized worklists filtered by:
- Their assigned department(s)
- Account type (IP vs. OP)
- Edit type (only accounts with specific types of errors)
- Days since service (prioritize accounts approaching timely filing deadlines)

### Priority Indicators

Accounts are flagged for priority review when:
- High-value account (total charges above threshold)
- Close to timely filing deadline (payer-specific — typically 90–365 days from service date)
- Sentinel edit present (high-severity compliance flag)

## Reviewing Charge Lines

### Opening an Account for Review

1. Click the encounter in the queue.
2. The account opens showing all charge lines for that encounter.
3. Each charge line shows: CDM description, CPT code, revenue code, units, charge date, charge amount, and any scrubbing flags.

### Evaluating a Charge Line

For each charge line, the reviewer verifies:
- **Was the service actually rendered?** — Cross-reference with the clinical record (orders, notes, imaging reports, lab results).
- **Is the CPT code correct?** — Verify the code accurately describes the service based on AMA CPT definitions.
- **Are required modifiers present?** — Common modifiers: 25 (significant separate E&M on same day as procedure), 59 (distinct procedural service), LT/RT (laterality), 26/TC (professional/technical component).
- **Is the revenue code correct?** — Revenue code must match the service category (110=Room/Board, 250=Pharmacy, 320=Radiology, etc.).
- **Is the quantity correct?** — Drug charges should reflect units dispensed; therapy charges should reflect minutes of service.
- **Are there CCI edits?** — National Correct Coding Initiative (CCI) edits bundle certain CPT code pairs that cannot be billed together without a modifier.

### Resolving Common Charge Edits

**Missing Modifier:**
1. Identify the required modifier from the edit description.
2. Add the modifier to the charge line in the modifier field.
3. Document the clinical rationale in the charge review notes field.
4. Clear the edit and approve.

**CPT Code Error:**
1. Review the clinical documentation to determine the correct code.
2. Change the CPT code to the correct code.
3. If the correct code is not in the CDM, request a CDM update from the charge integrity team.
4. Document the change reason.

**Duplicate Charge:**
1. Verify whether the service was rendered once or multiple times.
2. If duplicate: void the extra charge line with a reason code of "Duplicate."
3. If the service was actually performed twice: add documentation or clinical justification.

**Missing Charge:**
1. Reviewers identify missing charges by comparing the clinical record to the charge lines.
2. Add missing charges manually using the "Add Charge" function.
3. Select the correct CDM item.
4. Set the service date to the date the service was rendered.

**Bundling Edit (CCI):**
1. CCI edits prevent billing two codes for the same service when one is included in the other.
2. Options: void the included code, add a modifier (59 or X-modifier) if the service was genuinely separate.
3. Only add unbundling modifiers when the clinical documentation supports the services were separate and distinct.

### Approving Charge Lines

1. After resolving all edits: click "Approve" for each charge line.
2. Or "Approve All" to approve all lines on the account at once (use cautiously).
3. Approved charge lines move to the claim generation queue.

### Sending Accounts Back for Clinical Review

When charge review cannot be completed without clinical clarification:
1. Add a note to the account describing the question.
2. Route the account to the appropriate clinical or coding staff via the internal workflow routing tool.
3. The account is placed in a "Pending Response" status — pauses claim generation for that account.

## Charge Review Metrics

Key performance indicators:
- **Charge Review Productivity** — accounts reviewed per reviewer per day
- **Edit Resolution Rate** — % of edits resolved (vs. accounts routed for external clarification)
- **Charge Lag** — average days from service date to charge approval date
- **First Pass Clean Rate** — % of accounts that pass review without any edits

Target benchmarks:
- First Pass Clean Rate > 80%
- Charge Lag < 3 days for outpatient, < 5 days for inpatient

## Best Practices

1. Prioritize accounts by timely filing deadline — a claim denied for timely filing has zero recovery value.
2. Never add a modifier without clinical documentation to support the unbundling — false modifiers are a compliance risk.
3. Void charges for services not rendered — do not simply move the charge to another encounter.
4. Document all charge changes with a reason code — audit trails are essential for compliance reviews.
5. Escalate coding questions to medical coders, not clinical staff — coding decisions require coder expertise.
6. Conduct monthly charge review performance reviews — track edit types to identify systemic charge capture issues that could be fixed at the source.
