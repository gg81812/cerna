SMART App Launch Framework

The SMART App Launch Framework connects third-party applications to Electronic Health Records systems. Apps run against a FHIR API and launch from within or outside an EHR. The launch framework includes:
- EHR launch sequence: Apps launched from within an EHR context
- Standalone launch sequence: Apps launched outside the EHR
- OAuth 2.0 authorization: Scopes for patient-level, user-level, and system-level access
- OpenID Connect: Identity layer for provider and patient authentication

SMART Scopes

Scopes follow the pattern: context/type.permission
- patient/Patient.read — read patient data
- user/Observation.read — read observations for current user
- launch — request EHR launch context
- openid, fhirUser — request identity token

Backend Services

SMART Backend Services authorization uses JSON Web Tokens (JWT) signed with RS384 or ES384. Used for bulk export, analytics pipelines, and server-to-server data sharing.

Cerner-Specific Implementation

Cerner supports SMART on FHIR through its developer portal. Apps must be registered and go through a provisioning process. Cerner Ignite APIs expose FHIR R4 resources behind SMART authorization.
