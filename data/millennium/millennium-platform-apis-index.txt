Overview

Oracle Health Millennium Platform provides APIs across Oracle Health products built on the Millennium platform. These APIs allow you to use the HL7 FHIR standard in your SMART application.

Important Notice: Oracle no longer supports DSTU 2 FHIR APIs. Update applications to use R4 as soon as possible to prevent service interruptions.
