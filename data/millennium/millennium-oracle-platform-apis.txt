Oracle Health Millennium Platform

Oracle Health Millennium Platform

Oracle Health Millennium Platform provides APIs across the Oracle Health products built on top of the Millennium platform. These APIs allow you to use the HL7 FHIR standard in your SMART application.

Caution:
 Oracle no longer supports DSTU 2 FHIR APIs. For more information, see the 
FHIR DSTU2 End of Support
 announcement on the Oracle Health Developer Forums. This functionality is replaced by the R4 version. Update your applications to use R4 as soon as possible to prevent interruptions to service. Contact your Oracle representative for information on implementing R4.

Questions?
 See the 
Oracle Health Developer Forums
 for support and to connect with other developers across multiple API venues.
